# 掌柜智库 index.html 玻璃拟态改造设计

## 目标

只调整 `掌柜智库/atguigu/web/page/index.html` 的聊天视图，使聊天区域具备克制的玻璃拟态质感，同时让答案内容更紧凑、易读，并保留现有明暗主题、SSE 流式输出、Markdown 渲染、历史记录、图片展示和导入视图功能。

## 视觉方向

采用“克制的玻璃拟态”方向：主区域使用低饱和柔光、细微网格和半透明层叠制造深度；消息内容保持阅读优先，不使用高亮霓虹或大面积渐变。亮色主题以雾白、冷灰和淡蓝紫为主，暗色主题以深石墨、靛蓝和青色微光为主。

## 改造范围

### 聊天主区域

- 为 `.main` / `.chat` 增加分层背景：柔和径向光晕、低对比网格、轻微玻璃遮罩。
- 为聊天列增加半透明玻璃面板、边框和内阴影，避免背景效果直接干扰答案。
- 保留当前滚动、居中宽度和响应式布局。

### 消息层级

- 保留“掌柜智库助手”头像与名称，增加名称到答案正文之间的呼吸留白。
- 用户消息继续使用独立气泡；助手答案改为轻玻璃内容层，避免厚重卡片感。
- 进度面板、答案和图片之间使用紧凑但明确的垂直节奏。

### 答案排版

- 在写入 Markdown 渲染前，将连续多余空行压缩为最多一个空白段落。
- 保留代码块、列表、标题和图片结构，不改变 Markdown 语义。
- 适度收紧正文行高、标题间距、列表间距和图片间距，避免答案区域出现过多空白。

### 约束与验证

- 不修改 `chat.html`、`import.html`、后端 Python 文件或 API 地址。
- 不引入外部依赖和外部图片资源。
- 检查 HTML 中 CSS/JS 语法结构，确认所有关键选择器仍存在。
- 使用浏览器或本地页面预览确认亮色、暗色、窄屏、答案流式追加和历史答案显示正常。

## 不做的事情

- 不重构页面架构。
- 不调整业务文案、接口协议、进度节点或上传逻辑。
- 不把玻璃拟态扩展到导入视图，避免超出本次聊天页美化范围。
